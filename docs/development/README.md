# Development Documentation

This directory provides developer guides, environment setup protocols, branching workflows, coding standards, and team responsibilities for contributors to **Fitora**.

---

## 📑 Documents in this Section

- **[setup.md](setup.md)**: Local machine prerequisites, environment configuration (`.env.example`), installation walkthrough, and verification checks.
- **[git-workflow.md](git-workflow.md)**: Git branching strategy (`main`, `develop`, feature branches), commit message conventions (Conventional Commits), and PR review checklist.
- **[coding-guidelines.md](coding-guidelines.md)**: Code standards across frontend and backend, architectural layering constraints, naming conventions, and testing practices.
- **[team-roles.md](team-roles.md)**: Role definitions, module ownership, and code review responsibilities across the engineering team.

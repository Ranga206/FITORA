# UI & UX Documentation

This directory contains the user interface design system, typography scales, color palettes, component guidelines, information architecture, navigation hierarchies, and screen specifications for **Fitora**.

---

## 📑 Documents in this Section

- **[design-system.md](design-system.md)**: Modern wellness design tokens, color palette (dark and light themes), typography, spacing scale, component styles, and micro-interaction principles.
- **[navigation.md](navigation.md)**: Information architecture, primary routing tree, desktop sidebar / header layouts, and mobile bottom navigation structure.
- **[screens.md](screens.md)**: Detailed screen-by-screen specifications for the Dashboard, Nutrition Hub, Fitness Hub, Awareness Center, Habit Tracker, Progress Analytics, Leagues, and Profile screens.

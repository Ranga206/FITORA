# Feature Specifications: Fitora

This directory contains the in-depth functional and behavioral specifications for all modules in **Fitora**.

---

## 🏛️ The Three Core Pillars

Fitora is built around three foundational pillars:

1. **[Nutrition](nutrition.md)**: Nutrition profiles, BMI screening context, calorie estimation, meal planning, and food tracking.
2. **[Fitness](fitness.md)**: Exercise directory, workout plans, active workout tracking, volume history, and consistency monitoring.
3. **[Awareness](awareness.md)**: Curated lessons explaining the science (*the "WHY"*) behind nutrition, fitness, sleep, and lifestyle habits.

---

## ⚙️ Supporting Systems

These systems support and reinforce the Three Core Pillars:

- **[Habit Tracking](habits.md)**: Daily lifestyle checklists, customizable frequencies, and habit-specific streaks.
- **[Progress Analytics](progress.md)**: Visual analytics of daily, weekly, and monthly trends across diet, workouts, and consistency.
- **[Gamification](gamification.md)**: XP economy, level progression, active streaks, milestone badges, challenges, and weekly competitive leagues.

---

## 🔮 Future Scope Notice

- **Artificial Intelligence (AI)**: Any AI-based meal generation, natural language food parsing, or automated computer vision coaching is strictly designated as a **future optional extension**.
